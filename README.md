# Seres Migratorios — web

Sitio de **Seres Migratorios**, colectivo fotográfico de la diáspora venezolana en Buenos Aires. Estático y bilingüe (ES por defecto, EN bajo `/en/`), construido con Astro, Tailwind CSS y TypeScript, y publicado en Netlify.

Las convenciones del repo, los comandos y el checklist previo a cada PR están en [AGENTS.md](AGENTS.md), compartido por Codex, Claude Code y otros agentes. El diseño aprobado vive en `design/` (fuera del build).

Para trabajar con agentes, consultar [la guía de configuración](docs/agentes.md): incluye las skills disponibles, los auditores y cómo abrir el checkout correcto. Claude Code conserva su entrada en [CLAUDE.md](CLAUDE.md).
