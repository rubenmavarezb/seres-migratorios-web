- [tracking-wide pisa text-etiqueta](tracking-wide-vs-text-etiqueta.md) — un tracking-* literal en .boton/.caja-nombre gana sobre el 0.04em de text-etiqueta vía --tw-tracking compartido; fix correcto es tracking-(--text-etiqueta--letter-spacing), no un valor literal.
- [Line-height de "etiqueta" es por componente](etiqueta-line-height-is-per-component.md) — leading-[N]/leading-none en .boton/.caja-nombre/BloqueFicha no es un token faltante: el rol etiqueta comparte solo letter-spacing (0.04em), el line-height difiere a propósito por componente (JSX de referencia lo confirma).
- [Pseudo-elemento de área de toque vs. padding-box](pseudo-area-de-toque-padding-box.md) — un `::before absolute` con inset negativo sobre un host `relative` con border entrega inset−border, no inset; medido 40px en vez de 44px en Nav/CajaNombre chica — sumar el border-width al inset pedido (-inset-y-2, no -inset-y-1.5 con border-2).
- [text-xs no pisa leading-none](text-size-utility-no-pisa-leading-none.md) — a diferencia de tracking-wide, text-xs/text-etiqueta no fijan --tw-leading propio: leen el compartido, así que el leading-none de .caja-nombre/.boton sigue ganando. No marcar esa combinación como hallazgo.
